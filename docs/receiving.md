# 입고 검수 절차

이 문서는 교육용 예시입니다.

## 입고 검수 순서

트럭이 도착하면 입고 담당자는 먼저 발주서 번호와 거래명세서를 대조한다. 이어서 박스 수량을 세고, 박스 겉면에 찌그러짐이나 젖은 흔적이 없는지 확인한다. 이상이 없으면 PDA로 상품 바코드를 스캔해 WMS에 입고 수량을 등록한다. 등록이 끝난 상품은 지정된 로케이션으로 옮겨 적치한다.

## 입고 수량 불일치

거래명세서 수량과 실제 박스 수량이 다르면 입고 등록을 멈추고 차이 수량을 입고 이상 보고서에 기록한다. 부족분은 공급처 담당자에게 당일 연락하고, 초과분은 별도 보류 구역에 보관한다. 파손된 상품은 사진을 찍어 보고서에 첨부하고 반품 대기 구역으로 옮긴다. 입고 이상 건은 창고 관리자 확인 후에만 WMS에 반영한다.
